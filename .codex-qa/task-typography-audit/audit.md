# 任务页字体审查

## 范围

- 页面：NeoWorker「任务 > 需要关注」列表视图
- 目标：对齐 Codex 的轻量、清晰、系统字体排版
- Codex 参考：OpenAI Sans 仅使用 400/500；回退字体为 `-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`

## 1. 调整前

- 截图：`01-before.jpeg`
- 健康度：需优化
- 标题与状态大量使用 560–650 的合成字重，英文和中文都显得偏黑。
- 任务标题、状态、负责人和时间的字号差距太小，只能依靠粗细区分层级。
- 更新时间使用等宽字体，视觉上像技术日志，不像任务信息。

## 2. 调整后

- 截图：`02-after.jpeg`
- 健康度：良好
- 任务页改用 Codex 同类系统字体栈，并关闭浏览器合成粗体。
- 任务标题改为 500；说明文字改为 400；分区标题最多使用 600。
- 标签数字、更新时间与负责人恢复比例字体，行高与次级字号同步放松。
- 保留现有颜色、表格结构和交互，只调整排版层级。

## 可访问性说明

- 字号与行高得到提升，密集列表的可读性更好。
- 本次截图审查无法证明完整的缩放、键盘和屏幕阅读器兼容性；相关交互测试仍由现有组件测试覆盖。
