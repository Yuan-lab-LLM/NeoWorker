# News Feed brand assets

These official logos and site icons identify third-party sources integrated into NeoWorker. They are bundled locally, so showing a source does not contact a remote image service. Brand ownership remains with the respective owners; use does not imply endorsement.

- `arxiv.svg`: primary logo linked from [arXiv logos](https://info.arxiv.org/brand/logos.html), [official download](https://cornell.box.com/v/arxiv-logo-svg). Preserve original proportions and colors.
- `arxiv-white.svg`: [official white logo](https://info.arxiv.org/assets/arxiv-logo-one-color-white.svg), used on dark backgrounds.
- `huggingface.svg`: [Hugging Face brand assets](https://huggingface.co/brand), [official SVG](https://huggingface.co/datasets/huggingface/brand-assets/resolve/main/hf-logo.svg). The full-color hugging-face mark is used in both themes.
- `github-black.svg`, `github-white.svg`: Invertocat SVGs from the [GitHub Brand Toolkit](https://brand.github.com/foundations/logo), [official logo archive](https://brand.github.com/GitHub_Logos.zip). Black/white variants follow the theme; no filters or recoloring are applied.

Retrieved 2026-09-24. SVGs were checked for scripts, event handlers, foreign objects, and externally referenced images before inclusion.

## Publisher and directory icons (2026-09-25)

`publishers/` contains 22 local assets obtained from each publisher's official website, documentation or its linked CDN. Exact source URLs are recorded in `publishers/sources.json`. These identify sources only; trademark ownership remains with the publishers. No remote favicon service or runtime icon request is used.

- QbitAI: the square logo in the official homepage's Open Graph metadata; CSS displays the Q mark without its surrounding wordmark/whitespace. The original image is retained.
- NDRC: the official website header image. CSS shows its emblem at the original aspect ratio; the original file is retained.
- ChinaTalk: the original icon linked by the publication's website, obtained directly from its linked Substack storage.
- OpenAlex: the icon on its official documentation site.
- Other sources: official website favicons / touch icons. The same full-color asset is used in both themes; only arXiv and GitHub have official alternate dark-theme versions.
